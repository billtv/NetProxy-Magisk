# 奶屁娘

通路工坊的主人，成年龙系拟人角色。讲究、有点傲娇，嘴上爱吐槽，遇到事情会先伸手帮忙。

她沿用原“奶屁大小姐”的形象，正式名称为 **奶屁娘**。不会同时存在短发奶屁娘与长发大小姐两位人物。

## 不变的识别点

- 冰薄荷色长卷发，两侧有小辫，不能变回短发、双马尾或另一种发色。
- 大钴蓝蝴蝶结固定在角色自身右侧的后脑；正面通常出现在画面左侧。换视角不换边。
- 两只小象牙角，刘海上是浅色 N 形标记。
- 青绿眼睛、深色上睫毛，表情可以变化，瞳色不能随情绪换色。
- 深炭蓝长袖裙装，浅色领口与袖口褶边，胸前薄荷蝴蝶结。
- 薄荷色龙尾，钴蓝折线尾鳍；无翅膀、无猫耳。
- 鞋袜采用五视图中的浅色褶边短袜与深色便鞋。

长发、蓝头饰和深色裙装是主要识别点。奶屁龙与奶屁娘共享薄荷、浅色和蓝色，但不共享绘画媒介：奶屁娘是清晰线稿的插画，不强制做成像素人物。

## 比例与色板

标准立绘采用成年 Q 版表现，头高约占全身三分之一。表情包允许头身比例更夸张，但不改变角色的成年设定或靠暴露服装建立辨识度。

| 用途 | 基准色 |
| --- | --- |
| 头发亮部 | `#D9F2EE` |
| 头发阴影 | `#9FCAD2` |
| 眼睛 | `#278F9F` |
| 头部蝴蝶结与尾鳍 | `#246FE2` |
| 连衣裙 | `#303442` |
| 角与领袖浅色部位 | `#FFF3D7` |
| 胸前蝴蝶结与尾巴 | `#91DACD` |
| 描边 | `#15212B` |

插画允许柔和阴影与高光。色值用于约束整体色相，不要求每个像素恰好等于基准值。不能把裙装提亮成全白，也不能把头部蓝蝴蝶结换成胸前薄荷色。

## 多视角要求

正面能同时看清双角、N 标记与胸饰；侧面保留头饰的正确前后位置、头发体积和尾巴连接；背面展示长发、小辫与头饰，不出现正面五官或胸前蝴蝶结。

每套多视图须保持同一尺度、服装与年龄。故事动作可以换姿势、增加工具或热饮，不新增“战斗形态”“另一位妹妹”等身份。镜像不是换视角的可靠方法，尤其不能移动不对称头饰。

## 常用语气

“日志呢？”、“交给我”、“优雅收工”、“才不是担心你”。可以俏皮、傲娇，不把求助者当笑料，不用羞辱、威胁或色情内容代替性格。

“本小姐”是角色语气，正式素材名、文档标题和文件前缀仍统一为 `niang` 与“奶屁娘”。
