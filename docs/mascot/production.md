# 角色创作规范

制作前先读[角色关系](./index)、[奶屁龙规格](./dragon)和[奶屁娘规格](./niang)，再下载标准图。下面的文字不是替代参考图的捷径；只凭“可爱的薄荷色龙”重新生成，会得到另一只龙。

## 事实源与文件

| 内容 | 事实源 |
| --- | --- |
| 角色身份、关系与不可变特征 | 本组文档 |
| 奶屁龙已选轮廓 | `public/mascots/dragon/reference.png` |
| 奶屁龙可编辑矢量母版 | `public/mascots/dragon/base.svg` |
| 奶屁娘已有形象 | `public/mascots/niang/reference.png` |
| 奶屁娘补全结构 | `public/mascots/niang/turnaround.png` |
| 表情清单 | `public/mascots/stickers.json` |
| SVG 表情与结构稿生成代码 | `scripts/build-mascots.mjs` |

以上路径均相对仓库的 `docs/`。素材随文档站发布，不依赖作者电脑上的临时目录或隐藏文件夹。下载入口见各角色页和[表情包页](./stickers)。

## 奶屁龙制作

1. 先对照参考图和 SVG 母版，不改变头身比例、角、五官位置或尾巴轮廓。
2. 修改需要表达动作的图层；不把 PNG 塞进 `<image>` 后称为矢量还原。
3. 原图未提供的角度先补结构稿，对照正侧背面检查，不能声称是原图的精确背面。
4. 表情修改五官与小范围姿态。新增道具属于独立 `props` 图层，不覆盖主要识别点。
5. 保持透明背景、平涂色板与像素阶梯边界，不使用模糊、任意角度旋转和全身拉伸。
6. 与基准图并排检查，再检查目标小尺寸。图层运动后必须补齐关节衔接，避免透明孔洞。

交给代码型 AI 的提示词：

```text
为 NetProxy 的奶屁龙制作 [动作或表情]。
先阅读 /mascot/dragon 与 /mascot/production，并以 reference.png 和 base.svg 为依据。
保留原图轮廓、头身比例、象牙双角、额头阶梯 N、方眼、浅色腹部、蓝色背鳍和折线尾鳍。
输出纯 SVG 路径与可编辑图层，不能嵌入 PNG、Base64 或外部图片。
仅改变表达该动作需要的部位，保持透明背景、固定色板和像素边界。
附基准对照与小尺寸预览；未有参考的角度注明补全，不能伪称 1:1。
不接入软件、不改业务状态、不生成第三位角色。
```

### 重建与检查

```sh
cd docs
node scripts/build-mascots.mjs
node scripts/build-mascots.mjs --check
npm run check
npm run build
```

生成代码从纯路径母版派生表情，不需要原始位图解码库。脚本不重新调用生图模型，不覆盖奶屁娘 PNG。改母版后重新导出奶屁龙 PNG，不能只更新 SVG 留下旧预览。

## 奶屁娘制作

使用生图模型，把已有形象与五视图作为参考图片一起输入。每次生成一个明确动作；不要一次要求十几张小人物，导致五官、服装和文字都难以验收。

可复用提示词：

```text
用途：NetProxy 原创角色奶屁娘的 [立绘／多视图／表情包]。
参考图：reference.png 是身份参考，turnaround.png 是服装与结构参考。
同一位成年 Q 版龙系少女，不是新人物：冰薄荷长卷发及侧辫、角色右后侧大蓝蝴蝶结、
象牙双角、浅色 N 刘海标记、青绿眼睛、深炭蓝长袖裙装、浅色领袖褶边、
胸前薄荷蝴蝶结、薄荷龙尾及蓝色折线尾鳍。
动作：[具体姿势]；表情：[具体情绪]；道具：[必要时填写]。
保持参考图的清晰插画线稿、身份与服装，透明背景，不裁掉头饰和尾巴。
多视图保持尺度、服装和不对称头饰位置；背面不出现五官或胸饰。
表情包文字必须是 “[准确文字]”，粗体清晰，不遮脸。
禁止短发替换、猫耳、翅膀、换色、另一个角色、联名标记与水印。
```

额外提醒：模型“已经看过参考”并不等于结果一致。逐张检查头饰所在侧、双角数量、刘海 N、尾鳍和胸前蝴蝶结；错误先修图，不把错误补进设定。

## 表情包规格

- 两位各 16 张，总计 32 张；每张独立文件，不用一张总览代替。
- 标准发布文件为透明 PNG，画布 512×512，单张不超过 512 KiB。
- 人物与文字都在画布内；文字通常 2～7 字，边缘保留空间。
- 奶屁龙保留像素轮廓；奶屁娘采用深描边与浅色外轮廓。
- 中文必须逐字核对。可以在生成后单独排文字，但不能把缺字或错字当作创意。
- SVG 是奶屁龙的编辑源，不作为 Telegram 静态贴纸直接上传；PNG 是导出产物。
- 文件命名采用 `01-received.png` 等编号和动作名，角色通过上级 `dragon/` 或 `niang/` 区分。
- 下载包是素材包，不表示已创建或上传 Telegram 贴纸集；表情关联由发布者设置。

## 验收清单

- [ ] 只有奶屁龙、奶屁娘两个正式角色，名称和身份正确。
- [ ] 奶屁龙是像素风、纯 SVG 路径；没有混入旧的圆滑插画小龙。
- [ ] 奶屁娘保留长发大小姐形象，没有回到短发旧人物。
- [ ] 多视图的双角、头饰、服装和尾巴一致，背面没有正面标记。
- [ ] 动作没有拉伸整个角色，图层连接不露洞，减少动画设置有效。
- [ ] 文字、透明背景、512×512 尺寸和 512 KiB 上限检查通过。
- [ ] 小尺寸、浅色和深色背景均可识别。
- [ ] 新增素材入库、清单同步、链接有效；不改动代理业务或软件界面。
