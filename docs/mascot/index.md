# 奶屁的两位伙伴

“奶屁”这个名字，来自作者对奶龙的喜爱，以及 NetProxy 的缩写 NP。名字留下了亲切和一点调皮，形象则走自己的路：一只喜欢开路的小龙，一位嘴硬心软的工坊主人。

正式角色只有 **奶屁龙** 与 **奶屁娘**。奶屁龙始终是像素小龙；奶屁娘沿用原“奶屁大小姐”的长发形象。“大小姐”可以是她说话的口气，但不是第三位角色。

## 通路工坊

奶屁娘在一条安静的小巷里开了一间通路工坊。门口的牌子写着：“不保证一铲就通，但不会把你丢在半路。”

她画图、检查工具，也负责提醒大家先看路标。奶屁龙住在地板下面，听见开工就探出头来；听见收工，通常比谁都快。

小龙有一次信心满满地挖了半天，最后从工坊的饼干柜里钻了出来。奶屁娘叉着腰问：“我要的是通路，你怎么通到点心去了？”它抱着饼干，认真指了指柜门：路确实通了。

从那以后，他们约定：奶屁娘先确认方向，奶屁龙再开路。小龙找到出口时，总会带回一颗蓝色小石头；她嘴上说“这有什么好得意的”，却把石头整整齐齐地摆在窗台上。

有人来求助，两位会一起迎接。她说“日志呢？”，它说“我来康康”。忙完之后，一杯热饮、一块饼干，就是工坊最隆重的庆功宴。

## 两位的相处

| | 奶屁龙 | 奶屁娘 |
| --- | --- | --- |
| 身份 | 原创穴居小龙，工坊开路员 | 成年龙系拟人角色，工坊主人 |
| 性格 | 贪睡、爱吃、有点得意；做事认真 | 讲究、略傲娇、爱吐槽；可靠且护短 |
| 擅长 | 探路、挖洞、发现意想不到的出口 | 规划、检查、整理线索与照顾伙伴 |
| 小习惯 | 以为抱着工具睡着也算值班 | 说着“才不是担心你”，先把热饮递过来 |
| 关系 | 独立的搭档，不是她的宠物 | 独立的搭档，不是小龙的人形变身 |

挖洞、路标和工坊是角色故事的比喻，不代表 NetProxy 的真实网络协议、可达性或安全承诺。角色也不代表与奶龙、Clawd 或其他品牌存在授权合作。
